#     arf_ws_<舰种>_cost = 裸装基础 + Σ(各槽位配件的工厂占用)

#   · complete_effect 调 ARF_WS_Penalty_<舰种>，把「占用 N 座」折算成
#     industrial_capacity_factory = -N ÷ 全国军工厂数；若 N 超过全国总数，
#     上限取总数，避免出现低于 -100% 的产能。
#   · 建造天数固定不随配件变化（炮舰 90 天，其余 365 天）。
#   · 建造完成后发放 1 件该舰种装备；装备数值 = 基础值 × (1 + 当前方案加成)，
#     加成由设计台的隐藏精神经 equipment_bonus 写入。
#   方案本身不立即生效，在下一次开工时被采纳。
