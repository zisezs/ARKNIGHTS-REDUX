# 莱塔尼亚 (LTN) · 国策树配套决议
#
# 三段式（原版 AFG 的实证写法）：
#   complete_effect = 点击那一刻   ·  modifier = 存续期内生效   ·  remove_effect = 计时到期
#
# 本 mod 的三条硬规矩（都踩过）：
#   · 决议没有 completion_reward 这个键（那是国策的），写了整条作废
#   · 计时决议不写 cancel_trigger —— 块内是「与」，条件一翻转会被静默自取消
#   · 决议里的可见性一律用 has_completed_focus 接国策，不新增旗标
#
# 图标全部核过存在于原版 interface/decisions.gfx
# ============================================================================
