#  我和柳德米拉的回忆录 —— 决议系统
#  · 一条决议 = 一章回忆；**开局即解锁**（不挂旗标，靠年份 date 门槛逐章开放）
#  · 决议只负责「开门」：先把 node 设成该章首节点，再调 REU_Ludmila_Play_Chapter
#    台词、立绘、场景全在 common/scripted_effects 的台词表里，本文件不写剧情
#  · 分类页里的「进入主席办公室」入口面板见 common/scripted_guis（同一分类）
#  · 末条【模块开关】= 隐藏/显示整个模块（分类保留，只收起其余决议与入口）：
#    由每条决议 visible/available 里的 NOT = { has_country_flag = REU_ludmila_module_hidden }
#    与入口面板的 visible 共同实现（2026-09-13 增，维护说明见 docs/REU_Ludmila_Office_对话引擎指南.md §6.9）
#
#  【加一章回忆录 = 改四处】
#   1. scripted_effects：按章节编号写该章 node（编号规则见该文件头）
#   2. scripted_localisation：REU_GetLudmilaText 里补 node → loc key
#   3. localisation：写中文
#   4. 本文件：复制下面任意一块，改 id / 年份 / node / 图标 / 本地化 key
#      （visible/available 里的模块开关 NOT 从句照抄保留）
#
#  【年份门槛】date > 该年 1 月 1 日。开局是 1094.6.1，所以 1095 章要到 1095 年才可点。
#             只写了一半的章节把 complete_effect 留成 WIP 提示即可，玩家点它是空操作。
# ==============================================================================
