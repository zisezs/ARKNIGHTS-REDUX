#       common/decisions/categories/Ursus_Unification_War_categories.txt）。

# 参与方 / 目标池（18 个乌萨斯系 TAG，二者相同）：
#   URS 乌萨斯帝国
#   UFA/UEA/UTA 第四·第八·第三集团军军管区
#   UCM/ULB/UFS 苏维埃游击组织·自由乌萨斯阵线·民族军团
#   UFE 科雷马边疆区 / REU 感染者游击队

#   CYB 切里亚宾公爵领 / KZC 哥萨茨
#
# 引擎要点（与 RHL_war_decisions.txt 同一套写法，已验证）：
#   · declare_war_on = { target = X type = annex_everything } 是脚本效果，
#     直接开战、不经正当化流程，不受本 mod 开局规则 allow_wargoals = FOCUSES_ONLY 限制。
#   · 目标国不存在 / 就是自己 / 已与其交战 / 是自己附庸 —— 本条自动隐藏，
#     战争结束后重新出现，故**不写 fire_only_once**，可反复使用。
#   · 每条只花政治点，没有冷却；作战顺序完全由玩家自己决定。
#
# 解锁：1101.1.1 之后可用。日期门槛写在每条决议的 available 里（分类本身不隐藏），
#       因此 1101 年前整组决议可见但点不动，tooltip 提示「需在 1101 年 1 月 1 日之后」。
#
# 与既有分类的区别（避免 UI 混淆，两处都保留了独立实现）：
#   · 本分类   Ursus_Unification_War           中文名「乌萨斯全境统一」
#              —— 18 个乌萨斯系 TAG 互宣，1101 年起，与方法/派系无关，任何乌萨斯势力都能点。
#   · 既有分类 Ursus_Unification_War_Decisions_GUI  中文名「乌萨斯统一战争」
#              —— 原 mod 东乌萨斯起义链的后续（ursus_unifier 8 国，需 East_Ursus_Unification_After
#                 旗标 + 150 天，目标固定为 URS / 卡西米尔等），属于既有剧情流程，本次未改动。
#     两者在「向 URS 宣战」这一点上存在重叠，若只要一套，删掉本文件的对应条目即可。
#
# AI 权重（2026-09-15）：全 18 条 ai_will_do = factor 10000 —— 玩家与 AI 均可发起统一战争。
#   ⚠ 这会与 mod 既有的「东乌萨斯起义」链（East_Ursus_Unification_After）在
#     「向 URS 宣战」这一点上重叠；如需改为玩家专属，把各条改回 base = 0 即可。
