# ──────────────────────────────────────────────────────────────
# 应用户要求取消所有限制：
#   - 无政体 / 国家的存在性等前置条件，开局即可使用；
#   - 无冷却（不再设置 RHL_co_cd_* 时限旗标）；
#   - 无一次性限制（fire_only_once 默认 no）；
#   - 唯一消耗是决议的 cost = X（政治点）。
# 保留项：
#   - allowed = original_tag RHL（决议归属莱茵生命本身，非使用限制）；
#   - 天空贷的 days_remove = 180（这是「180 天后偿付期到期 → 天空贷崩盘」的核心机制，非冷却）。
# 效果内部对已灭亡国家做了存在性判断（if limit country_exists），避免报错，不影响使用。

# 「异见」沿用 CLB 侧惯例：以 custom_effect_tooltip 表现，配稳定/政治点数值。
# 「外交 ±X」沿用 RHL_td 惯例：opinion_gain_monthly_factor；针对特定国家用好感动文件。
