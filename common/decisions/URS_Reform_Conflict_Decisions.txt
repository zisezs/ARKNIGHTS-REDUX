#  common/decisions/categories/URS_decision_categroies.txt；
#  本文件的顶层块名就是该分类键。
#
#  解锁路径（全部由国策置旗标）：
#    稳定议会 / 夺取议会 ← 初升的曙光（URS_council_decisions_unlocked）
#    冬季配给           ← 一五计划（URS_winter_rationing_unlocked）
#    新年后演讲         ← 何去何从（URS_new_year_speech_unlocked）
#    达莉娅的要求       ← 狂人的誓言 / 维特的独裁 完成后出现
#    政变线与邪魔线整合 ← 内卫被控（URS_fool_integration_unlocked）
#
#  矛盾机制：稳定议会与夺取议会互斥（夺取后前者消失），
#  夺取议会为 fire_only_once，代价是稳定度归零 + 政变风险。
#
#  【AI 权重】2026-09-15 配 URS_ai_strategy_plans.txt「AI 优先走圣愚政治线」。
#  2026-09-22 修正：原写法 `base = 0 + modifier { is_ai = yes factor = N }` 是
#  0 × N = 0，AI 一条都不会执行（表现为「乌萨斯不会同意达莉娅的要求」），现改为 base = N。
#  「达莉娅的要求」权重最高（圣愚线入场券）；「夺取议会」仍留 base = 0，不让 AI 走极端线。
# ==============================================================
