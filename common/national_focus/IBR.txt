
######################
## 伊比利亚 国策树 ##
## 五轴十一线 · 泰拉南疆 ##
######################
#
# 【版式约定】全部节点使用 relative_position_id 定位，除起点外没有任何绝对坐标。
#
#   y=0                         IBR_crossroads
#   y=1      经济轴 x=-12   政治轴 x=-4   陆军轴 x=+4   海权轴 x=+12   海嗣战争轴 x=+20
#   y=2   每条轴下挂两条线，分别位于本轴 x=-2 / x=+2（海嗣战争轴下挂三条：-2 / 0 / +2）
#   y=3.. 线内节点一律 relative_position_id = 本线线首，x 只取 -1 / 0 / +1
#
#   于是：单条线最宽 3 列，相邻两线之间恒有 2 列空隙，各轴互不侵入。
#   要挪动一整条线，只改它线首那一个 x；要加节点，只在 -1/0/+1 里挑空格。
#
#   列带：经济 -15..-9 ｜ 政治 -7..-1 ｜ 陆军 1..7 ｜ 海权 9..15 ｜ 海嗣战争 18..22
#   整树 38 列 × 8 行，共 85 个国策。
#
#   连线规则：任何前置都只向下一层（dy=1）或跨过合并层（dy=2），横向不超过 1 列，
#   所以不会出现长斜线。合并节点（两条线汇成一格）固定用 x=0。
#   例外有二：y=0 起点放射到五个轴心——那五条长线就是“五轴”的示意，不是错误；
#   洗海覆潮行动由海嗣三条线尾 dx=±2、dy=1 汇入，同样是有意为之。
#
#   互斥关系：政治甲/乙两条线互斥（保守 or 开放）；
#   陆军甲/乙两条线不互斥——两线共用同一条「审判之火」阶梯：
#   甲线强化组织度与突破，乙线强化补给与补充；走完一条到三级，两条全走合成四级满配。
#   海权甲/乙两条线同样不互斥——两线共用「大深海舰队」阶梯：
#   甲线偏舰炮/队列，乙线偏潜艇/登陆；愚人号·再航再推一级，两条全走即五级满配。
#   海嗣战争三线同样不互斥——共用「我的剑，将劈开海潮！」阶梯：
#   三条线线尾各推一级，洗海覆潮行动收束至四级满配；告伊比利亚同胞书需工厂数量 > 150。
#   经济与海权的两条线互不冲突，可以全部走完。
#
######################
