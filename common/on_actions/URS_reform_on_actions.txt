# ============================================================================
# 乌萨斯 (URS) · 阶段树切换钩子
# ============================================================================
#
# 做什么：阶段一「乌萨斯之梦」(URS_dream) → 阶段二「回到起点」(URS_return_to_start)。
#
# 用 on_monthly_URS（原版口径：该国作用域、每月一次；先例 on_monthly_KZM /
# on_monthly_IBR）。不用 on_monthly + every_country —— 那会把次数乘上场上国家数。
# 同名 on_action 跨文件合并，所以新建本文件即可。
#
# 【占位闸门】设计稿口径是「小皇帝在开局前两年会进行尝试改革，然后引用阶段性国策树」。
#   本项目剧本开局日 = 1094.6.1，所以这里用“满两年”当天作闸门。
#   正式版应替换成「一系列内容和改革判定」——比如按阶段一树的完成度/旗标来判，
#   改下面 limit 即可，切换动作本身不用动。
#
# ============================================================================
on_actions = {

	on_monthly_URS = {
		effect = {
			if = {
				limit = {
					NOT = { has_country_flag = URS_reform_tree_loaded }
					date > 1096.5.30
				}
				URS_load_reform_tree = yes
			}
		}
	}
}
