#  · 四门课 × 10 级；主属性 Lv1=11% 每级 +1% → 20%；副属性 Lv1=±5% 每级 ±1% → ±14%。
#  · 数值成长由**角色级动态修正符** REU_sokolov_training_dm 承载（数值写角色变量）。
#  · 可受训者（花名册）见 ROSTER；选择 = 一个国家旗标，训练走"国家侧派发"。
#  · 变量：
#      角色 REU_sok_<skill>_lv / _prim / _sec      —— 该角色自己的练度
#      国家 REU_mir_<key>_<skill>_lv / _br         —— 每个成员的国家侧镜像
#      国家 REU_sel_<skill>_lv / _cost / _br       —— 当前受训者的镜像副本（面板读数用）
#  · 教训：HOI4 不支持 scripted_effect 的 $参数$；has_political_power 不吃 >=（写 > N-1）。

# —— ① 侦察好手：角色侧升级（THIS = 受训者）——
REU_Sokolov_Training_Scout_Scoped = {
	add_to_variable = { REU_sok_scout_lv = 1 }
	if = {
		limit = { check_variable = { REU_sok_scout_lv = 1 } }
		set_variable = { REU_sok_scout_prim = 0.11 }
		set_variable = { REU_sok_scout_sec = 0.05 }
		add_unit_leader_trait = REU_scout_adept
	}
	else = {
		add_to_variable = { REU_sok_scout_prim = 0.01 }
		add_to_variable = { REU_sok_scout_sec = 0.01 }
	}
	# 动态修正符幂等重挂（doc：已存在则刷新，不会叠加）
	add_dynamic_modifier = { modifier = REU_sokolov_training_dm }
	REU_Sokolov_Training_Check_Graduation = yes
}

REU_Sokolov_Training_Scout_Up = {
	if = {
		limit = {
			REU_Train_Has_Target = yes
			check_variable = { REU_sel_scout_lv < 10 }
		}
		set_variable = { REU_sok_pay = REU_sel_scout_cost }
		multiply_variable = { REU_sok_pay = -1 }

	}
}

			remove_unit_leader_trait = REU_sok_br_scout_b
