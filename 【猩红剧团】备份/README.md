## 恢复方式

直接把本目录下的 `common/`、`events/`、`history/`、`interface/`、`localisation/`、`gfx/`、`docs/`
覆盖回 mod 根目录即可。

`_共享文件/` 下的内容需要单独覆盖回 mod 根目录（它保留了 `common/...` 等原始相对路径）。
覆盖前请先确认共享文件没有被其它会话改动过，避免回滚掉别人的修改。
