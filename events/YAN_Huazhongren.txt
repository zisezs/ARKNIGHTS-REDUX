#  · 出场角色照原作：年 / 夕 / 说书人（煮伞居士，即夕）/ 黎（当铺掌柜）/
#    嵯峨（东国游方僧）/ 炎熔 / 克洛丝 / 乌有 / 阿然 / 逸川 / 廉子虚（回忆）；
#    朝廷侧用 椿（司岁台监正）/ 左乐 / 老天师。
#  · 起链 1096.1.1（除夕），每 60 天一环，见 YAN_sidestory_scripted_effects.txt。
#  · 设定要点：原作通篇不写「岁兽」「岁相」，只用「我们」「它」「神明」指代；
#    年给出的关键设定是——当「我们」苏醒、重新成为「我」，现在的年与夕都会消失。
#    这一条直接接上大炎的「代理人信任」机制，是本链的政治核心。
# ==============================================================================
