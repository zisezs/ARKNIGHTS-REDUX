# 分支不改变链条长度，只改数值与旗标（避免 2^8 组合）；唯一改变流程的是事件 1 的 B 分支：
#   它中止链条并上「灰厅的沉默」，90 天后由事件 17 再给一次回到事件 2 的机会。
# 内战在哪落地：SR1 / SR2 的建政、割州、部队与宣战全部集中在事件 16 的 B 分支。

# 2026-09-19 二改（用户要求「大幅度增加负面效果」）：
#   ① 链条里**每一个选项**至少扣 §R-10%§! 基础稳定度，越往后越重（终幕 -15%、开战 -25%）。
#      原先那些 +2%/+3%/+5% 的正向稳定度全部去掉，代价改由政治点、战争支持度、人力、经验承担。
#   ② 走和平路线（事件 16 选 A 签署宪法、不打内战）额外获得限期精神
#      §Y家族可能会倒闭，但绝不会变质§!：每周稳定度 §R-1%§!，持续 365 天。
#      ——家族没被武力清算，就继续在体制内烂着。
#
# ⚠ country_event 一律不写 major = yes（见 [[hoi4-major-event-scope-leak]]）
#
# 2026-09-23 AI 取向（人机叙拉古「必定打内战」）：
#   双选项事件全部补了 ai_chance —— 走 A 的一侧给 100，其余 30~50；
#   事件 1 的 B（中止链条 + 灰厅的沉默）与事件 16 的 A（和平过渡）除权重 0 外
#   还叠了 trigger = { is_ai = no }，AI 连选项都看不到，只剩 16.B 全面内战可点。
#   A 分支的偏好口径是「哪一侧攒战争支持度/陆军经验，AI 就走哪一侧」：
#   3.A/6.A 给陆军经验（换更强编制），2.A/4.A/8.A/10.A 给战争支持度（抬高投降界限）。
#   注入脚本 E:/tmp/src_cw_ai_chance.cjs（幂等，改权重改那张表重跑）。
